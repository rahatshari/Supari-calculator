# সুপারি হিসাব অ্যাপ (Supari Calculator)

কাঁচা-পাকা ও শুকনো সুপারি কেনা-বেচার সহজ, দ্রুত ও নির্ভুল হিসাব ক্যালকুলেটর এবং দৈনিক সুপারি ক্রয় খাতা।

## নতুন ও আধুনিক বৈশিষ্ট্যসমূহ (Key Features)

1. **আধুনিক সেটিংস আইকন ও দৈনিক ক্রয় খাতা টগল (Default: OFF)**:
   - অ্যাপের বাম পাশের উপরে আধুনিক সেটিংস আইকন দেওয়া হয়েছে।
   - সেখান থেকে প্রয়োজন অনুযায়ী **দৈনিক সুপারি ক্রয় খাতা** ফিচারটি চালু (ON) বা বন্ধ (OFF) রাখা যায়।
   - ডিফল্টভাবে এই ফিচারটি বন্ধ থাকবে যাতে সাধারণ ব্যবহারকারীরা কোনো জটিলতা ছাড়াই শুধুমাত্র দ্রুত হিসাব করতে পারেন।
   - চালু করলে হোম স্ক্রিন, হিস্ট্রি ও ক্যালকুলেটরে ক্রয় খাতার সব অপশন দৃশ্যমান হয়।

2. **কাঁচা-পাকা সুপারি ও দর যাচাই (Rate Checker)**:
   - কুড়ি, ঘা ও পিস অনুযায়ী দ্রুত হিসাব (২১ ঘা = ১ কুড়ি অথবা ২০ ঘা = ১ কুড়ি)।
   - দর যাচাই অপশনে কোনো নির্দিষ্ট পরিমাণের মোট টাকা লিখলে স্বয়ংক্রিয়ভাবে ১ কুড়ির দর ও ১ ঘার দর বের হয়ে যায়।
   - **ক্রয় খাতায় অ্যাড**: দর যাচাইয়ের ফলাফল থেকে সরাসরি **"🛒 এই হিসাবটি দৈনিক ক্রয় খাতায় জমা করুন"** বাটনে ক্লিক করে বিক্রেতার নামসহ খরিদ চালানে যোগ করা যায়।
   - **মূল হিসাবে অ্যাড**: এছাড়া দর যাচাই থেকে **"➕ কাঁচা-পাকা মূল হিসাব তালিকায় যোগ করুন"** বাটনে ক্লিক করে চলমান হিসাবে যোগ করা যায়।
   - **ক্রয় খাতার ভিতর দর যাচাই**: দৈনিক সুপারি ক্রয় খাতার ভিতরেও সরাসরি "🔍 দর যাচাই করে এন্ট্রি" অপশন যোগ করা হয়েছে।

3. **শুকনো সুপারির হিসাব**:
   - বস্তা অনুযায়ী ওজন ও সরাসরি মোট ওজন হিসাব।
   - খালি বস্তার ওজন স্বয়ংক্রিয় বাদ দেওয়ার সুবিধা।
   - ৮২ কেজি = ১ হাজার অথবা ৮০ কেজি = ১ হাজার নিয়ম নির্বাচন।

4. **মেমো রসিদ এক্সপোর্ট ও প্রিন্ট**:
   - উচ্চ রেজোলিউশনের JPG মেমো ছবি ডাউনলোড ও হোয়াটসঅ্যাপে শেয়ার।
   - এক ক্লিকে ক্লিপবোর্ডে টেক্সট কপি ও সরাসরি প্রিন্ট সাপোর্ট।

5. **হিস্ট্রি খাতা ও অফলাইন পিডব্লিউএ (PWA)**:
   - কোনো ইন্টারনেট ছাড়াই ১০০% অফলাইনে কাজ করে। মোবাইলে অ্যাপের মতো ইন্সটল করা যায়।

## লোকাল ডেভেলপমেন্ট কমান্ড (Local Development)

```bash
# ডিপেন্ডেন্সি ইন্সটল
npm install

# ডেভেলপমেন্ট সার্ভার চালু
npm run dev

# প্রোডাকশন ওয়েব বিল্ড
npm run build
```
